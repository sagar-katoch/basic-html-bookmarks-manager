# Basic HTML Bookmark Manager

## Overview

This is a simple, beginner-friendly HTML project that serves as a basic bookmark manager. It provides a categorized list of links to frequently visited websites. The page uses standard HTML elements like headings, lists, and anchor tags to display and organize bookmarks in a clean and accessible format.

## Features

- Categorized bookmarks: Primary and Secondary
- Uses HTML `<ol>` lists for organization
- Opens all links in new tabs
- Easy to modify and expand
- Lightweight and fast (no external dependencies)

## Preview

A basic webpage with two main sections:
- **Primary Bookmarks**: Commonly used sites like Google, YouTube, GeeksforGeeks, etc.
- **Secondary Bookmarks**: Additional links like Zomato and LinkedIn

## How to Use

1. Clone or download the repository.
2. Open `index.html` in any web browser.
3. Click on any link to open the corresponding website in a new tab.
4. You can customize the links by editing the `index.html` file in any text editor.
